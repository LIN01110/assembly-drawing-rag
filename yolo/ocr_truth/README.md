# OCR 真值转写工具包

目的：为 OCR 臂评估（字段准确率 / 技术要求 CER）制作 21 张图纸的人工真值。

## 文件

| 文件 | 作用 |
|------|------|
| `make_draft.py` | 从 `predict/gt_batch/*_result.json` 生成预填草稿 Excel |
| `ocr_truth_draft.xlsx` | **你要编辑的文件**（草稿已预填） |
| `vis/*.jpg` | 21 张检测可视化图，校正时对照 |
| `build_gt.py` | 校正完成后导出 `ground_truth.json` |

## 操作步骤（约 30 分钟）

1. 用 Excel/WPS 打开 `ocr_truth_draft.xlsx` 的「字段校正」页。
2. 逐行（每行一张图）对照 `vis/` 里的可视化图或原图：
   - 单元格内容**对** → 不动；
   - **错字** → 直接改；
   - 图纸里**没有**该字段 → 清空单元格；
   - 草稿为空但图纸**有** → 手动填上。
3. 「技术要求(草稿)」列：只保留真正的技术要求条目（形如 `1. 未注圆角 R3`），
   把误收进来的尺寸标注（如 `±0.2`、`Φ50`）删掉，每行一条。
4. 保存后运行：`.conda/python.exe ocr_truth/build_gt.py`
5. 告诉我一声，我来跑 OCR 臂评估并回填简历数字。

## 参考

- 「原始OCR文本」页是每张图的全部 OCR 原文，校正时可以翻看有没有草稿漏掉的信息。
- 真值口径：标题栏 12 字段 + 技术要求条目；尺寸标注不计入。
